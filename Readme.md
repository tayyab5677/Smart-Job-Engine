# Smart Job Matching Engine

A Python backend-style project that matches candidates with jobs
based on skills and experience.

## Features

- Object-Oriented Programming
- Dataclasses
- Type Hints
- Custom Exceptions
- Data Validation
- JSON Parsing
- Iterators and Generators
- Skill Matching
- Score Calculation
- Async/Await
- asyncio.gather
- File Handling
- pytest Testing
